# Sistem Manajemen Perpustakaan Kampus

Sistem Manajemen Perpustakaan Kampus merupakan program berbasis Java yang bertujuan untuk memudahkan petugas dalam mengelola koleksi dan lokasi penyimpanan buku, memantau data peminjaman, mengatur antrean mahasiswa, serta mencatat riwayat transaksi. Sistem ini membantu petugas menemukan informasi buku dengan lebih mudah, menjaga keteraturan proses peminjaman, dan mengurangi kesalahan dalam pengelolaan data. Program ini juga menerapkan enam struktur data sebagai bentuk penerapan konsep pemrograman Java dalam membangun sistem perpustakaan yang terstruktur dan efisien.
